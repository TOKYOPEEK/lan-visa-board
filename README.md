# ЛАН-ТАБЛО

Успеваешь ли ты сделать визу на этот LAN. Табло EU LAN-турниров по CS2 с визовыми
статусами для граждан РФ: сколько дней до старта, выдаёт ли страна визы, влезает ли
визовый цикл, когда закрывается регистрация.

Статика на [Astro](https://astro.build): без базы и бэкенда, всё читается из
закоммиченных JSON.

## Как устроены данные

| Файл | Что это | Кто обновляет |
|---|---|---|
| `data/tournaments.json` | нормализованный снапшот турниров с [cslans.com](https://cslans.com) | GitHub Action раз в 8 ч (`.github/workflows/update-data.yml`) |
| `data/countries.json` | визовые статусы стран Шенгена, по записи на страну, с `lastVerified` | руками, через PR |
| `data/config.json` | пороги (45/90 дней), курсы для сортировки, безвизовые страны, якоря гайда | руками |
| `src/content/eu-lan-visa-guide.md` | гайд, рендерится на `/guide` | руками |

Пайплайн (`scripts/fetch-tournaments.mjs`): cslans.com — статический SPA, датасет лежит
в `/js/data.js` как YAML-блоб в template literal. Скрипт забирает его одним HTTP-запросом
(идентифицируемый User-Agent с контактом), чинит YAML, нормализует в модель и валидирует
перед записью. Идентичность записи — имя+дата, не URL. При любой ошибке старый снапшот
остаётся на месте, а табло показывает его возраст — пустым оно не бывает.

Логика «успеваю/не успеваю» — в одном месте: `src/lib/feasibility.js`. Используется и при
сборке, и на клиенте (пересчёт от локальной даты пользователя).

## Команды

```sh
npm install
npm run fetch-data   # обновить data/tournaments.json с cslans.com
npm run dev          # localhost:4321
npm run build        # статика в dist/
```

## Деплой

Cloudflare Pages или Vercel: build command `npm run build`, output `dist/`,
переменная `SITE_URL` — прод-адрес (попадает в canonical, OG и sitemap).
Cron-воркфлоу коммитит свежий снапшот — пуш триггерит редеплой сам.

## Атрибуция

Данные о турнирах — [cslans.com](https://cslans.com), каталог ведёт Roope Leppänen
([@CS2LANS](https://x.com/CS2LANS)). Каждая строка табло ссылается на свою страницу
на cslans.com. Статусы стран — ручная курация, **не юридическая консультация**:
правила меняются, проверяй на официальных сайтах консульств.
